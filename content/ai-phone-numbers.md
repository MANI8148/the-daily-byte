## What is MCP Server
The MCP server is a solution for AI agents that require a phone number to receive SMS verification codes. This can be useful in various scenarios, such as automated account creation or SMS-based two-factor authentication. The repository, [sv-number/mcp-server](https://github.com/sv-number/mcp-server), provides a simple API for ordering a private number, reading the SMS verification code, and handing it back to the AI agent.

## Country Coverage
One of the key features of the MCP server is its extensive country coverage. With support for over 200 countries, this repository offers the widest coverage in its category. This means that AI agents can be designed to work with phone numbers from almost any country, making it a versatile solution for global applications.

## API Call Verification
Another significant advantage of the MCP server is its simple verification process. With just one API call, developers can check the status of a phone number and verify that it is working as expected. This streamlines the development process and reduces the complexity of integrating phone number verification into AI applications.

## Setup and Usage
To use the MCP server, developers can follow these steps:
```bash
# Clone the repository
git clone https://github.com/sv-number/mcp-server.git

# Install dependencies
npm install

# Start the server
node index.js
```
From there, developers can use the API to order a private number, read the SMS verification code, and hand it back to the AI agent.
