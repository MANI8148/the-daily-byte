## What Are AI Provenance Marks?

When an image or document is generated by an AI model, vendors often embed invisible markers—tiny text strings, metadata fields, or statistical fingerprints—to prove authorship. These markers can be:

* **Unicode text hygiene**: hidden characters that identify the model (e.g., “OpenAI‑Generated” encoded in zero‑width spaces).
* **Statistical rewrite hooks**: subtle alterations in pixel patterns or text distribution that signal AI origin.
* **C2PA metadata**: a standardized set of fields that record the creation chain, used by some platforms to verify authenticity.

While useful for tracking, these marks can be a nuisance when you want a clean, neutral file for publishing, sharing, or further processing.

## How It Works – A Quick Walkthrough

1. **Installation**  
   ```bash
   pip install watermarks-remover
   ```

2. **Command‑line usage**  
   ```bash
   watermarks-remover input.png output.png
   ```

   The tool automatically detects the file type, removes any known AI provenance markers, and writes a clean copy.

3. **Python API**  
   ```python
   from watermarks_remover import clean_file

   clean_file("report.pdf", "report_clean.pdf")
   ```

   The API returns a boolean indicating whether any markers were found and removed.

4. **Batch processing**  
   ```bash
   find . -type f -name "*.png" -exec watermarks-remover {} {}_clean.png \;
   ```

   This one‑liner cleans every PNG in a directory.

## Behind the Scenes – What the Tool Does

1. **Unicode Text Hygiene**  
   The tool scans for zero‑width spaces, non‑breaking spaces, and other invisible Unicode characters that are often used to embed text. It replaces them with standard spaces or removes them entirely.

2. **Statistical Rewrite Hooks**  
   By comparing pixel histograms or text n‑gram distributions against known AI signatures, the tool flags and removes subtle alterations that indicate AI rewriting.

3. **C2PA Metadata Stripping**  
   The Common Criteria for Provenance and Authenticity (C2PA) standard stores metadata in a JSON blob. The tool parses the blob and deletes any fields that reference AI vendors or generation timestamps.

4. **File‑Specific Cleaners**  
   Each format has a dedicated parser: Pillow for images, PyPDF2 for PDFs, python-docx for DOCX, and so on. This modularity keeps the codebase maintainable and extensible.
