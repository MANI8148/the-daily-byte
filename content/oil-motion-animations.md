## What is Oil-Motion?
Oil-motion is a Python library that provides a simple and intuitive way to create interactive web animations. ## Example Use Case
To demonstrate the capabilities of oil-motion, let's consider a simple example. Suppose we want to create a animated button that changes color when hovered over. We can use oil-motion to define the animation behavior, and then render the animation in the browser using JavaScript. Here's an example of how we might do this:
```python
import oil_motion as om

# Define the animation behavior
animation = om.Animation(
    selector='.button',
    keyframes=[
        om.Keyframe(0, {'background-color': 'blue'}),
        om.Keyframe(1, {'background-color': 'red'})
    ]
)

# Render the animation in the browser
animation.render()
```
This code defines a simple animation that changes the background color of a button from blue to red when hovered over.
